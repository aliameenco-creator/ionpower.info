# ION Power - WordPress website

Repository for the ION Power WordPress rebuild. The theme lives at the repository root; numbered releases (`vX.Y.Z`) carry `ion-power.zip`, which the in-WordPress updater installs.

| | |

| Original site | https://www.ionpower.info/ (Strikingly) |
| Hostinger site | https://mediumvioletred-camel-394493.hostingersite.com/ (temporary address; real domain connected manually at launch) |
| Hosting | Hostinger Cloud Professional, WordPress, LiteSpeed Cache, Hostinger plugins removed |

Admin logins, tokens and contact email addresses are never stored in this repository.

## Install / update

1. First install: upload `ion-power.zip` (Appearance → Themes → Add New → Upload), activate, click **Complete ION Power setup**.
2. Later releases then appear under Dashboard → Updates / Appearance → ION Power Updates.
3. After an update that changes page designs, use Appearance → **ION Power Pages**.

=== ION Power ===
Requires at least: 6.4
Requires PHP: 8.1
License: GPL-2.0-or-later

Custom theme for ION POWER (ionpower.info).

== Installation ==
1. Appearance → Themes → Add New → Upload Theme: ion-power.zip, then Activate.
2. Click "Complete ION Power setup" in the admin notice (permalinks, site title, Media Library images, pages, Main menu).
3. Settings → General → "ION Power form recipient" to change where contact messages are emailed (they are always saved under Enquiries).
